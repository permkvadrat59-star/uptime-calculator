# Калькулятор стоимости дата-центра — прототип

**Открыть:** https://permkvadrat59-star.github.io/uptime-calculator/

Демонстрационная страница калькулятора, свёрстанная в фирменном стиле сайта [uptime.ru](https://uptime.ru) (ЦОД ЭКСПЕРТ). Прототип для согласования интерфейса и логики расчёта — не официальный сайт компании.

## Что считает

Задаются мощность IT-нагрузки, мощность на стойку, уровень надёжности, площадка и тип объекта. Пересчёт мгновенный, без кнопки.

На выходе — капитальные затраты «под ключ» и удельная стоимость за кВт, количество стоек, расчётный PUE, годовые эксплуатационные расходы, простой срок окупаемости и структура CAPEX по семи статьям.

## Модель расчёта

| Параметр | Значение |
|---|---|
| Удельный CAPEX | 620 тыс. ₽/кВт (Tier II), 850 тыс. (Tier III), 950 тыс. (Tier III + сертификация) |
| Регион | коэффициент 0,86–1,00 |
| Реконструкция вместо нового строительства | коэффициент 0,83 |
| PUE | 1,40–1,60 с климатической поправкой по региону |
| Структура CAPEX | электроснабжение 31 %, холодоснабжение 21 %, здание и СМР 19 %, техприсоединение 10 %, слаботочные системы 7 %, проектирование и ПНР 7 %, резерв 5 % |
| OPEX | электроэнергия по тарифу и загрузке, персонал (6 + 7 чел. на МВт), обслуживание инженерки 3,5 %, прочее 1,8 % от CAPEX |
| Выход на загрузку | 30 % → 60 % → 80 % → 88 % |

Срок окупаемости простой, по EBITDA коммерческой модели, без учёта налогов, амортизации и стоимости финансирования.

Коэффициенты собраны по открытым отраслевым данным и заданы одним блоком в начале скрипта — заменяются без переписывания расчёта.

## Стиль

Дизайн-токены взяты с боевого сайта uptime.ru: шрифт Inter 300–600, `--blue-bright #0A4F68` для кнопок и акцентов, `--blue-dark #161D23` для тёмных секций, `--gray-light #F5F8F9` для фона, радиус скругления 8 и 12 px, заголовок первого уровня 36/48 px весом 500, поля ввода высотой 48 px.

## Технически

Одна самодостаточная HTML-страница без сборки и зависимостей. Изображения в WebP, общий вес около 330 КБ. Форма заявки не отправляется — это прототип.
